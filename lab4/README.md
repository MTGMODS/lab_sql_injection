# Лабораторна робота № 4 — Шифрована файлова система (EFS) Windows 11

Матеріали до ЛР №4 «Вивчення можливостей захисту шифрованої файлової системи (EFS)».

Коду тут немає — це вбудований механізм Windows. Робота: зашифрувати папку, отримати
сертифікат, експортувати його, під іншим користувачем переконатися, що доступу немає,
імпортувати сертифікат — і доступ зʼявляється.

---

## 0. Що потрібно (прочитай першим)

- **Windows 11 Pro** (або Enterprise). У **Home EFS немає** — пункт «Шифрувати вміст…»
  буде неактивним. Тому роби у **віртуальній машині з Windows 11 Pro** (Hyper-V або
  VirtualBox) або на Pro-системі.
- **Файлова система NTFS** (у Windows за замовчуванням так і є).
- **Другий обліковий запис** у цій же системі (звичайний локальний користувач) — щоб
  показати «Доступ заборонено».
- **Флешка** (або будь-яка папка) для експорту сертифіката.

> Суть демонстрації: EFS шифрує файл на випадковому ключі (FEK), а сам FEK — на твоєму
> **відкритому** ключі. Розшифрувати файл можна лише **закритим** ключем із твого
> сертифіката. Інший користувач цього ключа не має → «Доступ заборонено».

---

## 1. Створення зашифрованої папки і файлу

1. У своєму каталозі створи папку, напр. `C:\EFS_test`.
2. ПКМ по папці → **Властивості** → вкладка **Загальні** → кнопка **Інші/Додатково…**
3. Постав галочку **«Шифрувати вміст для захисту даних»** → **OK** → **Застосувати**.
   Назва папки стане зеленою.
4. Створи всередині документ (MS Word/Excel або звичайний `.txt`), напиши будь-який текст,
   збережи.

---

## 2. Консоль сертифікатів (mmc)

1. `Win+R` → `mmc` → **OK**.
2. Меню **Файл → Додати або видалити оснастку**.
3. Вибери **Сертифікати** → **Додати** → **Мого облікового запису користувача** → **Готово** → **OK**.
4. Розгорни: **Сертифікати — Поточний користувач → Особисті → Сертифікати**.
   Там буде твій сертифікат (призначення — **Encrypting File System**).

[МІСЦЕ ДЛЯ СКРІНШОТА 3: консоль з твоїм EFS-сертифікатом у розділі Особисті]

---

## 3. Експорт сертифіката (із закритим ключем)

1. ПКМ по сертифікату → **Усі завдання → Експорт** → **Далі**.
2. **«Так, експортувати закритий ключ»** → **Далі**.
3. Формат — залиш **.PFX** (за замовчуванням) → **Далі**.
4. Постав **пароль** (запамʼятай — знадобиться для імпорту) → **Далі**.
5. Вкажи імʼя файлу і місце (флешка), напр. `E:\my_efs.pfx` → **Далі → Готово**.

[МІСЦЕ ДЛЯ СКРІНШОТА 4: майстер експорту з вибором «експортувати закритий ключ» / встановлення пароля]

> Файл `.pfx` тримай у надійному місці: хто його імпортує і знає пароль — отримає доступ
> до твоїх зашифрованих файлів.

---

## 4. Перевірка захисту під іншим користувачем

1. Заверши сеанс (**Вийти**) і зайди в систему під **іншим** обліковим записом
   (або зроби це через «Змінити користувача»).
2. Спробуй відкрити файл із папки `C:\EFS_test`.
3. Отримаєш **«Доступ заборонено»** — бо в цього користувача немає твого закритого ключа.

[МІСЦЕ ДЛЯ СКРІНШОТА 5: повідомлення «Доступ заборонено» при спробі відкрити файл]

---

## 5. Відновлення доступу через імпорт сертифіката

1. Під цим же (іншим) користувачем відкрий `mmc` → додай оснастку **Сертифікати →
   Мого облікового запису** (як у кроці 2).
2. **Особисті → Сертифікати** → ПКМ → **Усі завдання → Імпорт**.
3. Вкажи файл `.pfx` з флешки, введи **пароль**, пройди майстер до кінця.
4. Знову відкрий файл із зашифрованої папки — тепер він **відкриється**.

[МІСЦЕ ДЛЯ СКРІНШОТА 6: успішно відкритий файл після імпорту сертифіката]

> Це демонструє: доступ визначає не обліковий запис сам по собі, а наявність
> закритого ключа з сертифіката.

---

## 6. Значення полів сертифіката (для звіту)

Двічі клацни по сертифікату → вкладка **Склад/Состав** → по черзі виділяй поля у верхньому
вікні й копіюй їхні значення знизу. Для звіту випиши хоча б: **Версія, Серійний номер,
Алгоритм підпису, Видавець (Issuer), Дійсний з/по, Суб’єкт (Subject), Відкритий ключ,
Використання ключа, Application Policies (Encrypting File System)**.

---

## Що показувати під живу здачу (порядок)

1. Зашифрував папку (зелена назва) → створив файл.
2. Показав сертифікат у mmc → експортував `.pfx` на флешку.
3. Зайшов під іншим користувачем → «Доступ заборонено».
4. Імпортував сертифікат → файл відкрився.
5. Коротко пояснив схему FEK + відкритий/закритий ключ + агент відновлення.

Готовий звіт — у файлі `ЗВІТ_ЛР4.md`: впиши свої значення сертифіката й встав 6 скріншотів.
