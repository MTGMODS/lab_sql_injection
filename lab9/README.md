# Лабораторна №9 — підготовка експерименту

Скрипт створює **власні** тестові ZIP з уже відомими паролями, словники і шаблон таблиці для Excel. Підбір паролів скрипт **не робить** — час заміряєш у програмі відновлення, яку дав викладач.

## Запуск

Потрібен лише Python 3 (стандартна бібліотека, без pip).

Windows (подвійний клік):

```
lab9\prepare.bat
```

або в терміналі:

```bat
cd lab9
python prepare_lab9.py
```

Каталог результату за замовчуванням: `lab9/Lab9_experiment/`. Інший шлях:

```bat
python prepare_lab9.py --out D:\Lab9_experiment
```

## Що з’явиться

```
Lab9_experiment/
  plain/secret.txt
  archives/A_digits/     A1..A6  паролі 1, 12, 123, 1234, 12345, 123456
  archives/B_mixed/      B3=A1b, B4=A1b2, B5=A1b2C
  archives/C_layout/     C_gfhjkm = gfhjkm  («пароль» латиницею)
  dictionary/dict_with_mixed.txt      є A1b2C
  dictionary/dict_without_mixed.txt   немає A1b2C
  results/manifest.txt
  results/results_template.csv
```

Формат архівів: ZIP, традиційне шифрування ZipCrypto, один файл `secret.txt` всередині.

## Що клікати в програмі відновлення

Працюй **тільки з цими архівами**. Паролі вже відомі — потрібен саме час.

1. Серія A: повний перебір, алфавіт **лише цифри**, довжина від 1 до довжини файлу.
2. Серія B: повний перебір, алфавіт **A–Z, a–z, 0–9**.
3. Серія C: повний перебір, алфавіт **a–z**, довжина 6.
4. Ті самі архіви — режим словника:
   - спочатку `dict_with_mixed.txt`;
   - для `B5_len5.zip` окремо `dict_without_mixed.txt` (пароля там немає — має не знайти).

Час, швидкість (pwd/s) і «знайдено / ні» записуй у `results_template.csv`. Далі в Excel: графік часу від довжини (вісь Y логарифмічна) для A і B, стовпчики перебір vs словник.

Якщо довгий пароль не знаходиться за 10–15 хвилин — зупини, у таблиці напиши «не завершено за N с» і порахуй очікуваний час:

`T_сер ≈ |Σ|^L / (2 × V)`

де V — швидкість з короткого успішного прогону.
