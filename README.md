# Лабораторні роботи з курсу «Безпека програм та даних»

Усі матеріали зібрані в одній гілці. Кожна лабораторна — окрема папка:

| Папка | Тема |
|-------|------|
| [`lab1/`](lab1/) | Механізми захисту ОС Windows (користувачі, ACL, аудит) |
| [`lab2/`](lab2/) | Захист реєстру Windows 11 |
| [`lab4/`](lab4/) | Шифрована файлова система (EFS) Windows 11 |
| [`lab9/`](lab9/) | Стійкість паролів ZIP-архівів |
| [`lab10/`](lab10/) | SQL-ін’єкції (PHP + SQLite, вразлива / захищена версії) |
| [`lab11/`](lab11/) | Стійкість паролів точок доступу Wi-Fi |

У кожній папці є `README.md` (як виконувати) і, де потрібно, шаблон звіту.

## Швидкий старт для ЛР №10

```bash
cd lab10
chmod +x start.sh
./start.sh
# або: docker compose up --build
```

Вразлива версія: порт `8080`, захищена: `8081`.
